# 📊 Key Performance Indicators (KPIs) - QA Assistant System
**Project Title:** QA Assistant System & Smart AI-Powered Bug Triage
**Team Name:** Bug Busters1  
 


---

## 📌 Overview
تُعتبر مؤشرات الأداء الرئيسية (**KPIs**) الأساس الذي نقيس به نجاح المشروع، جودة النظام البرمجي، ومدى دقة وكفاءة اقتراحات الذكاء الاصطناعي (AI Triage) طوال دورة حياة التطوير.

---

## 🛠️ 1. System Quality KPIs (مؤشرات جودة السيستم)
تهدف هذه المؤشرات لضمان خلو التطبيق من الأقطار الحرجة والتأكد من استقرار المنظومة.

| KPI Metric | Formula / Calculation | Target Goal | Description |
| :--- | :--- | :--- | :--- |
| **Test Case Pass Rate** | $(Passed \div Total) \times 100$ | $\ge 90\%$ | نسبة الـ Test Cases الناجحة من الإجمالي. |
| **Defect Density** | $Total\ Bugs \div Total\ Modules$ | $< 5$ | معدل الأخطاء بكل وحدة برمجية في النظام. |
| **Defect Removal Efficiency** | $(Bugs\ Found\ Before\ Release \div Total) \times 100$ | $\ge 95\%$ | نسبة الباجات التي تم اكتشافها قبل التسليم النهائي. |
| **Test Coverage** | $(Tested\ Features \div Total\ Features) \times 100$ | $100\%$ | نسبة الميزات التي تم اختبارها مقارنة بالإجمالي. |
| **Mean Time to Detect (MTTD)** | $Sum\ of\ Detection\ Times \div Total\ Bugs$ | $< 2$ Days | متوسط الوقت المستغرق لاكتشاف الخطأ. |
| **Mean Time to Resolve (MTTR)** | $Sum\ of\ Resolution\ Times \div Total\ Bugs$ | $< 5$ Days | متوسط الوقت المستغرق لحل الخطأ وإغلاقه. |

---

## 🤖 2. AI Performance KPIs (مؤشرات أداء الذكاء الاصطناعي)
تقيس هذه المؤشرات مدى كفاءة الـ AI في مساعدة فريق الـ QA في فرز الأخطاء[cite: 2, 4].

| KPI Metric | Formula / Calculation | Target Goal | Description |
| :--- | :--- | :--- | :--- |
| **Classification Accuracy** | $(Correct\ AI\ Suggestions \div Total) \times 100$ | $\ge 80\%$ | دقة اقتراحات الـ AI لخطورة وأولوية الباجات. |
| **Duplicate Detection Precision** | $(True\ Duplicates \div Total\ Flagged\ as\ Duplicate) \times 100$ | $\ge 75\%$ | دقة اكتشاف الباجات المكررة بدقة. |
| **Recommendation Acceptance Rate** | $(Accepted\ AI\ Suggestions \div Total) \times 100$ | $\ge 70\%$ | نسبة اقتراحات الـ AI التي وافق عليها فريق العمل. |
| **Time Saved in Triage** | $Manual\ Triage\ Time - Automated\ Triage\ Time$ | $\ge 50\%$ Time Saved | حجم الوقت الموفر مقارنة بالفرز اليدوي التقليدي. |
